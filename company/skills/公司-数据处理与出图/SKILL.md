# 数据处理与出图（公司版）

公司工具包在 `/opt/company/kit/`，用它能少写代码、格式统一。**不要把整张表读进对话。**

## 第 1 步：先看数据（必做）
```bash
python3 /opt/company/kit/peek.py <文件>                 # 所有 sheet 概况
python3 /opt/company/kit/peek.py <文件> --sheet 明细 --header 3   # 表头不在第 1 行时
```
看输出里的「可能的问题」。然后用 3~5 句话告诉用户：每列理解成什么、打算怎么清洗、哪些字段看不懂。
**有疑问先问，得到确认再继续。**

## 第 2 步：写 script.py 计算（不要在对话里手算）
- 输出目录：`~/<部门>/02_输出/<YYYYMMDD>_<用户名>_<任务简称>/`，代码存成同目录 `script.py`，能直接重跑。
- 清洗规则：去全空行；重复行只报告、问过用户再删；日期统一 YYYY-MM-DD；金额/数量转数字，转不了的**列出来**，不要悄悄丢掉；不擅自填补缺失值。
- 每一步删了/改了多少行，写进 `清洗记录.txt`。
- 终端输出只打印汇总结果（不超过 30 行），不要打印整张明细表。

## 第 3 步：出图（用公司出图函数）
```python
import sys; sys.path.insert(0, "/opt/company/kit")
from charts import line, bar, bar_compare, combo
line(周列表, {"入库金额": 数值列表}, "入库金额 · 近8周", "万元", "趋势.png")          # 看变化 → 折线
bar(类别, 数值, "各仓库出库金额 · 2026-09", "万元", "仓库.png")                    # 比大小 → 柱状（>8 类自动横向排序）
bar_compare(类别, {"上月": a, "本月": b}, "各仓库出库金额 · 本月 vs 上月", "万元", "对比.png")
combo(月份, 金额, 达成率, "销售额与达成率", "万元", "达成率", "combo.png", rate=True)  # 金额 + 比率
```
- 占比且不超过 5 类才用饼图（自己用 matplotlib 画，颜色用 蓝 2F6FB0、绿 3A9A5B、橙 D9822B、灰 8C8C8C）。
- 标题写「什么数据 · 时间范围」，单位写清楚。

## 第 4 步：出 Excel（用公司表格函数）

