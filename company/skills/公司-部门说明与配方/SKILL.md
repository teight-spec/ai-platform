# 部门说明与部门配方

工具：`python3 /opt/company/kit/dept.py <子命令>`（自动找部门文件夹）。

## 1. 任务开始：先跑 start
```bash
python3 /opt/company/kit/dept.py start
```
一次看全：部门说明（已确认的术语、字段口径、常用文件、汇报习惯）+ 部门配方清单 + 周报说明是否已设置。
- 部门说明里写了的口径**直接照用，不要再问用户**；没写的才问。
- 用户这次的任务和某个配方是同一类（同样的文件、同样的算法），**先用配方**（见第 4 节），不要从头写代码。

## 2. 任务结束：把新确认的口径记下来
本次和用户确认过的口径（字段含义、计算规则、筛选条件、单位、汇报对象的习惯……），在最后回复里列成
「建议记入部门说明」，**用户同意后**逐条写入：
```bash
python3 /opt/company/kit/dept.py note --section 字段口径 --by <用户名> "入库金额 = 数量 × 含税单价，不含退货单"
```
- section 只能是：术语、字段口径、常用文件与来源、汇报习惯、其他。
- 一条一句话、写结论不写过程，写成「名称 = 口径」或「名称：说明」；用户没明确同意的不要写。
- **同名口径已存在**时工具不会写入，会列出旧条目：这是口径变了还是另一回事？先问用户。确认要改：
  `dept.py note --replace 入库金额 --by <用户名> "入库金额 = 新口径"`（旧内容自动记进 `05_模板/部门说明_修改记录.md`）。
- **篇幅上限约 3000 字**（每次任务都要读，越长越费钱）。超过时工具不写入：用 `note-list` 列出全部条目，
  和用户一起合并同类（`note --replace 编号 "合并后的内容"`）、删掉过时的（`note-del 编号 --by <用户名>`），再写新条目。
- start 输出里有【提醒】（快到上限、很久没复核）时，**只在任务最后提一次**：请用户看一遍 `note-list`，
  用户说没问题就运行 `dept.py note-review --by <用户名>` 记下复核日期。

## 3. 可重跑的 script.py（所有数据任务都这样写）
```python
import sys; sys.path.insert(0, "/opt/company/kit")
from runio import io_args, save_summary
inputs, out = io_args(["~/资材/01_原始数据/入库明细_0923.xlsx"], "~/资材/02_输出/20260924_张三_入库汇总")
# ……读 inputs[0]、计算、出图、出 Excel，文件都写进 out ……
save_summary({"入库总金额(元)": total, "有效行数": n, "按仓库(元)": by_wh})   # 结论里引用的数字都放进来
```
- `结果摘要.json` 会记下这些数字、输入文件和输入表头，结论里的数字要和它一致（可追溯）。
- 数字转成普通数值（pandas 的也可以，会自动转）；字典最多嵌套一层。

## 4. 部门配方
**什么时候建议存**：任务以后还会重复（每周/每月同一类文件），并且用户确认结果对了。在最后回复里问一句
「这个任务以后还会做吗？要不要存成部门配方，下次直接重跑？」，用户同意再存：
```bash
python3 /opt/company/kit/dept.py recipe-save --name 月度入库汇总 --from <本次输出目录> \
    --desc "按仓库汇总月度入库金额（ERP 入库明细导出）" --by <用户名> --note "退货单不计入" "金额单位：元"
```
工具会用样例重跑一次、记下验收值；重跑失败说明脚本依赖了别的文件或手工步骤，要先改好。

**用配方**：
```bash
python3 /opt/company/kit/dept.py recipe-run 月度入库汇总 --input <新文件> --user <用户名>
```
- 提示「格式不一致」时**停下来问用户**（文件换了格式？放错了？），不要自己改脚本硬跑。
- 口径要改：改输出目录里的 script.py → 用户确认结果 → `recipe-save --overwrite`（旧版自动存进 历史/）。
- 结论只引用输出目录 `结果摘要.json` 里的数字；出图、PPT、标注照公司技能做。

**检查配方**（平台升级后管理员会跑；用户问「配方还好用吗」时也可以跑）：
```bash
python3 /opt/company/kit/dept.py recipe-check
```

## 注意
- 部门说明、配方都在部门自己的文件夹里（05_模板、04_技能），只有本部门能看到。
- 临时文件用 `mktemp -d` 建自己的临时目录，不要用固定文件名（同部门可能有别人同时在用终端）。
